# Enigma Mystery

Moordmysteries om te spelen, te lopen en te lezen — www.enigmamystery.com (NL en EN).

- `index.html` taalkeuze · `nl/` en `en/` de site · `spel/` alle spelbestanden · `assets/` stijl, logo, beelden
- Pagina's bouwen: `python3 _tools/build_site.py` (spellen, boeken en teksten staan bovenin dat script)
- Spellen overzetten uit de oude graveyardfiles-repo: `python3 _tools/migrate_games.py <map>`
